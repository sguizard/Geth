# History

How Geth was built, kept as written at the time (October 2026); the pages outside `history/` describe the current version. Paths and names refer to the cluster it
was developed on.

- [feasibility.md](feasibility.md): the feasibility decision (can free, self-hosted models drive
  Nextflow agents through routine nf-core analyses?), the lessons that shaped version 1, and the results
  of each version since.
- [progress.html](progress.html): the development progress page, phase by phase.
- [blueprint.html](blueprint.html): how an analysis moved through Geth 1.x, where each part ran on the
  cluster, and the plans that followed.
- [rannoch.html](rannoch.html): Geth 2.0 and 2.1, from Nextflow's agent preview to Geth's own agent harness,
  then projects (`geth legion`) and the comparison with paid models.
- [testing.html](testing.html): how Geth is tested: unit tests, benchmarks, sparse deliveries, comparisons.
- The first experiments ("spikes") and their results are in [`spikes/`](../../spikes/).
