One analysis, from question to report

Agents propose and fixed checks decide. Nothing runs before you approve, a retry can never change the samples, and every number in the report is traced back to the results.

Diagram 4 · phase 11 experimental

Can agents design and build a single-cell analysis?

A small team of agents, each step checked, tested on public data with known answers. Three arms answer three questions: can the agents design the analysis, write its steps, and write the Nextflow pipeline itself? No agent-written code runs before you give the go.

Diagram 5 · phase 12 planned

Agents in sandboxes, off the front node

Eddie allows agents only inside sandboxes. Phase 12 moves every agent step that launches no jobs to a small job on a worker node, and puts each agent in a container that only sees what its step needs.
