What broke and what we built

Lessons turned into guardrails

critical

An operator rewrote the samplesheet unprompted, turning a technical replicate into a fake biological replicate. The pipeline still succeeded.

Plan-diff gate: every attempt is compared with the approved plan; grouping and file changes are refused.

frequent

Plans invent parameters (strandedness, skip_qcach). nf-core only warns, so they would silently do nothing. Qwen did it once in 4 plans.

Schema guard (built): params are checked against the pinned pipeline schema before launch, with “did you mean” hints. Fixed in one retry every time.

frequent

Structured answers fill in fields the model never stated (total_reads: 1000000 for 50,000 reads). Reports misread units in raw MultiQC tables.

Facts first: prompts name every field to report; results tool emits rounded, labelled tables; report numbers are cross-checked.

v1.0

The planner checked a correct scRNA plan, but the structured final answer turned its JSON parameters into protocol,aligner,…. JSON nested inside a text field does not survive the hand-off.

v1.1: parameters and samplesheet are handed over as lists; the last plan that passed CHECK_PLAN is kept as fallback; approval refuses any plan that fails the check.

platform

Agent preview limits: tool inputs cannot be Path; a failing tool kills the agent; compute nodes cannot submit SGE jobs.

Workarounds: absolute paths as text on the shared filesystem; tools always exit 0 and report errors as text; the driver runs on node1q01 (≤ 4 CPUs).
